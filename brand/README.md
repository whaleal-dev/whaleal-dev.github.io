# Whaleal 品牌 Logo 资产

透明母版来自 `whaleal-master-brand-assets-transparent`，原样放在本目录。站点只引用常用尺寸，不再生成中间尺寸。

## 源文件（本目录）

| 目录 | 内容 |
|------|------|
| `icons/` | 品牌包原图 |
| `logos/` | 横版 / 深色 / 白字 / 堆叠 logo PNG |
| `svg/` | 彩色、横版、单色、无损矢量 |

## 站点使用的常用尺寸

| 文件 | 尺寸 | 用途 |
|------|------|------|
| `../favicon/favicon-16.png` | 16 | 浏览器标签 |
| `../favicon/favicon-32.png` | 32 | 浏览器标签 |
| `../favicon/favicon-48.png` | 48 | 浏览器 / PWA |
| `../favicon/apple-touch-icon.png` | 180 | iOS 主屏 |
| `../favicon/favicon-192.png` | 192 | Android / PWA |
| `../favicon/favicon.png` | 512 | Gatsby manifest、OG |
| `../favicon.ico` | — | `/favicon.ico` |
| `../favicon/favicon.svg` | 矢量 | 现代浏览器 |
| `../images/whaleal-icon.png` | 512 | 导航 |
| `whaleal-icon.svg` / `whaleal-logo.svg` | 矢量 | 方形 icon / 横版字标 |

更换品牌时直接覆盖上述文件，不要再跑生成脚本。
