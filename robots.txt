# 搜索引擎（含百度）—— 必须放行
# 🔴 2026-11-24：这些显式组必须**自带完整规则**，不能只写 `Allow: /`。
#    robots.txt 的组选择是「最具体的 User-agent 组胜出、且不继承 * 组」——
#    只写 Allow: / 时，GSC 会把 * 组的 Disallow /auth/ /404 与 Content-Signal
#    报为「忽略的规则」（用户所见警告）。把规则逐组复刻可消除告警，
#    并让按「首个匹配组 / 行顺序」实现的解析器也正确屏蔽 /auth/ /404。
#    Disallow 写在 Allow 之前：兼容行顺序语义的解析器（Google 按最长路径，不受顺序影响）。
