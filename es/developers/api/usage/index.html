6. Uso del período actual — GET /open/v1/usage

CampoTipoDescripción
periodstringClave del período de facturación, UTC yyyyMM (p. ej. 202609)
planstringUna etiqueta de visualización en la org, con valor predeterminado OPEN_BETA. El plan facturado está en «Planes y facturación», no en este campo
messageCountintEnvíos de este período (número de solicitudes)
billedSegmentsintSegmentos facturables de este período (un mensaje largo cuenta como varios; solo cuentan los aceptados por el proveedor)

messageCount es cuántos envíos se han sometido; billedSegments es cuántos segmentos se cuentan. La cuota incluida y si el exceso se factura están en la suscripción, no en este endpoint.
